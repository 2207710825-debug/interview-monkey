面试猴能帮你什么
  • 🎙 会议助手：实时转写会议内容，自动提取关键词、金额、结论、待办
  • ❓ 疑问解答：对会议内容提问，快速找到相关片段
  • 🎯 面试陪练：念题给你听，你口头作答，对照参考要点复盘
  • 📚 练习题库：视觉 / 3D视觉算法工程师方向系统化题库
  • 🔒 纯本地：所有数据存在你自己设备上，不上传
快捷键

Ctrl+M 开始/结束会议 · Ctrl+Enter 提问/加入记录 · Ctrl+F 搜索题库 · Ctrl+1~4 切换会议/纪要/解答/陪练 · 顶栏「📌 窗口置顶」可让窗口悬浮。

正直使用

面试猴帮你提前准备、练好表达、记清会议。请勿在正式面试/考试中实时作弊使用。

面试猴 · 把会议说清楚、把面试练顺 · 数据只存本地，不上传
