# 使用与常见问题

如何开始一次会议记录：打开应用，点击「开始会议」，对着麦克风说话即可实时转文字；语音不可用时，可在输入框粘贴文字后点「加入记录」。

如何提问：在「疑问解答」页输入问题，例如「价格是多少」「谁负责跟进」，系统会检索会议内容并返回相关片段。

快捷键：Ctrl+M 开始或结束会议；Ctrl+Enter 提问或加入记录；Ctrl+F 搜索题库；Ctrl+1 到 4 切换会议、纪要、解答、陪练模块。

数据位置：会议与练习记录保存在本机用户数据目录（InterviewMonkey 文件夹），不会上传。

如果本地部署了大模型 Ollama，系统会自动优先使用本地模型回答；否则使用内置的规则化摘要兜底。
